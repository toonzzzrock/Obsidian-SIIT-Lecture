# Part 1: Gray-Level (Intensity) Transformations

## 1. Mathematical Concept & Mapping Function (Slides 2–3)

An intensity transformation is a point-processing operation mapping an input intensity $r$ to an output intensity $s$ via a transformation function $T$:
$$s = T(r)$$

- For an 8-bit image, $r, s \in [0, 255]$ (or normalized to $[0, 1]$).
- **Thresholding Function (Slide 2):**
  $$s = T(r) = \begin{cases} 0 & \text{if } r < m \quad (\text{Dark}) \\ L - 1 & \text{if } r \ge m \quad (\text{Light}) \end{cases}$$
  where $m$ is the threshold value. A smooth, continuous sigmoidal curve can also be used to smoothly expand contrast around $m$ without harsh binary clipping.

## 2. Negative Transformation (Slides 4–5)

$$s = T(r) = (L - 1) - r$$
For an 8-bit image ($L = 256$):
$$s = 255 - r$$

```
   Input (r)    Output (s = 255 - r)
      0 (Black)  ------> 255 (White)
    128          ------> 127
    255 (White)  ------>   0 (Black)
```

### Purpose & Example

- **Medical Imaging (Slide 4):** In digital mammograms or chest X-rays, subtle lesions and microcalcifications surrounded by large dark areas are difficult for the human eye to discern. Inverting the image to a bright background with dark anomalies leverages human visual sensitivity to dark features on light backgrounds.
- **Histogram Effect (Slide 5):** The histogram is mirrored horizontally: a distribution skewed toward the dark end ($0 \le r \le 50$) flips entirely to the bright end ($205 \le s \le 255$).

---

## 3. Logarithmic Transformation (Slides 6–7)

$$s = T(r) = c \cdot \log(1 + r)$$

### Why the Log Transformation is Used

1.  **Dynamic Range Compression:** It maps a narrow range of dark input levels into a wider range of output levels, while compressing high input values.
2.  **Fourier Spectrum Display (Slides 6–7):** The 2D Discrete Fourier Transform (DFT) of an image has a central 0-frequency DC peak that can reach values of $10^6$ to $10^7$, while high-frequency details may have values of order $10^0$ to $10^1$. Displaying $|F(u, v)|$ linearly yields a single white pixel at the center surrounded by total blackness.
    Applying $s = c \log(1 + |F(u, v)|)$ compresses this huge dynamic range into visible bands, rendering the surrounding diffraction patterns visible.

---

## 4. Power-Law (Gamma) Transformation & Gamma Correction (Slides 8–11)

$$s = c \cdot r^\gamma$$

```
   Curve Behavior:
   • γ < 1 (nth root):   Curves upward. Expands dark values (brightens dark images).
   • γ = 1:              Identity line (s = c · r).
   • γ > 1 (nth power):  Curves downward. Compresses dark values (darkens bright images).
```

### Physical Display Gamma Correction (Slides 10–11)

Cathode Ray Tubes (CRTs) and modern monitor controllers exhibit a physical power-law response between input voltage $V$ and emitted luminance $L_{\text{out}}$:
$$L_{\text{out}} \propto V^{\gamma_{\text{display}}} \quad (\text{where typically } \gamma_{\text{display}} \approx 2.2 \text{ to } 2.5)$$

If an uncorrected image is displayed, the monitor will darken all mid-tones and shadow details. To cancel this distortion, image acquisition systems apply a **gamma correction**:
$$s = r^{1 / \gamma_{\text{display}}} = r^{1 / 2.2} \approx r^{0.45}$$
When displayed, the combined system transfer function becomes linear:
$$\text{Output} = (r^{1/\gamma})^\gamma = r^1 = r$$

## 5. Walkthrough of Exercise 1 (Slides 12–15)

### Question 1: Explain why we need to add 1 in the log function as $\log(r + 1)$.

- **Mathematical Reason:** For digital images, minimum intensity is $r = 0$ (black). Since $\log(0) = -\infty$, evaluating $\log(r)$ at 0 is undefined and causes a mathematical singularity.
- Adding 1 shifts the input: when $r = 0$, $\log(0 + 1) = \log(1) = 0$. This ensures the output passes through the origin $(0, 0)$, mapping pure black to pure black.

---

### Question 2: Determine coefficient $c$ in the log transformation for 8-bit images ($0 \le r, s \le 255$).

We require that maximum input $r_{\max} = 255$ maps to maximum output $s_{\max} = 255$:
$$s_{\max} = c \cdot \log(1 + r_{\max})$$
$$255 = c \cdot \log(1 + 255) = c \cdot \log(256)$$
$$c = \frac{255}{\log(256)}$$

### Question 3: Determine coefficient $c$ in the power-law transformation for 8-bit images.

Equation: $s = c \cdot r^\gamma$.
We require that $r = 255$ yields $s = 255$:
$$255 = c \cdot (255)^\gamma \implies c = \frac{255}{255^\gamma} = 255^{1 - \gamma}$$
_(Note: If input $r$ is normalized to $[0, 1]$, then $1 = c \cdot 1^\gamma \implies c = 1$.)_

### Question 4: Compare natural logarithm ($\ln = \log_e$) with base-10 logarithm ($\log_{10}$). Is there any difference in the resulting images?

- **Mathematical Derivation (Slide 14):**
  Using the change-of-base formula $\log_b(x) = \frac{\log_a(x)}{\log_a(b)}$:
  $$s_{\text{base } e} = \left( \frac{255}{\ln 256} \right) \ln(1 + r) = \left( \frac{255}{\frac{\log_{10} 256}{\log_{10} e}} \right) \cdot \left( \frac{\log_{10}(1 + r)}{\log_{10} e} \right) = \frac{255}{\log_{10} 256} \log_{10}(1 + r) = s_{\text{base } 10}$$
- **Conclusion:** There is **no difference whatsoever**. The change-of-base factor cancels out entirely in the scaling coefficient $c$.

## 6. MATLAB `imadjust` Syntax and Mechanics (Slides 16–18)

```matlab
output = imadjust(img, [low_in high_in], [low_out high_out], gamma);
```

All parameters are normalized to the range $[0.0, 1.0]$.

- Any input $r \le \text{low\_in}$ is clipped to $\text{low\_out}$.
- Any input $r \ge \text{high\_in}$ is clipped to $\text{high\_out}$.
- Within $[\text{low\_in}, \text{high\_in}]$, the mapping follows:
  $$s = \left( \frac{r - \text{low\_in}}{\text{high\_in} - \text{low\_in}} \right)^\gamma \cdot (\text{high\_out} - \text{low\_out}) + \text{low\_out}$$

#### Question 2: Find output $s$ for input $r = 120$ when $p_1 = 0.1$, $p_2 = 0.8$, $p_3 = 0$, $p_4 = 1$, and $p_5 = 1$.

Since $p_5 = \gamma = 1$, the function is a straight line between $(p_1, p_3) = (0.1, 0)$ and $(p_2, p_4) = (0.8, 1)$.

1.  **Normalize input $r = 120$ to $[0, 1]$:**
    $$r_{\text{norm}} = \frac{120}{255}$$
2.  **Equation of the line:**
    $$\text{Slope } m = \frac{p_4 - p_3}{p_2 - p_1} = \frac{1 - 0}{0.8 - 0.1} = \frac{1}{0.7} = \frac{10}{7}$$

3.  **Evaluate inside brackets (Slide 18 handwritten steps):**
    $$s_{\text{norm}} = \frac{10}{7} \cdot \frac{120}{255} - \frac{1}{7} = \frac{1200 - 255}{7 \times 255} = \frac{945}{7 \times 255}$$
    Dividing $945$ by $7$:
    $$\frac{945}{7} = 135$$
    $$s_{\text{norm}} = \frac{135}{255}$$
4.  **Denormalize back to 8-bit integer:**
    $$s = s_{\text{norm}} \times 255 = \mathbf{135}$$

# Part 2: Histogram Equalization (HE)

## 1. Mathematical Formulation (Slides 19–21)

Given an image with $n$ total pixels and $L$ gray levels ($r_k$ for $k = 0, 1, \dots, L - 1$):

- **Probability of occurrence (PDF):**
  $$p(r_k) = \frac{n_k}{n}$$
- **Cumulative Distribution Function (CDF):**
  $$\text{CDF}(r_k) = \sum_{j=0}^{k} p(r_j) = \sum_{j=0}^{k} \frac{n_j}{n}$$
- **Discrete Mapping Function:**
  $$s_k = T(r_k) = \text{round}\left( (L - 1) \cdot \sum_{j=0}^{k} p(r_j) \right) = \text{round}\left( \frac{L - 1}{n} \sum_{j=0}^k n_j \right)$$

# Part 3: Image Contrast Metrics & Statistical Measures

## 1. Root-Mean-Square (RMS) Contrast (Slides 26–27)

RMS contrast is the standard deviation of pixel intensities:
$$\text{RMS Contrast} = \sigma_x = \sqrt{\frac{1}{MN} \sum_{r=1}^M \sum_{c=1}^N (I_{rc} - \bar{I})^2}$$
Where the mean intensity is $\bar{I} = \frac{1}{MN} \sum_{r=1}^M \sum_{c=1}^N I_{rc}$.

### Two Equivalent Computational Formulas (Slide 27):

- **Formula 1 (Direct Definition):**
  $$\sigma_x^2 = \frac{1}{n} \sum_{i=1}^n (x_i - \bar{x})^2$$
- **Formula 2 (Computational Shortcut via Expected Values):**
  $$\sum_{i=1}^n (x_i - \bar{x})^2 = \sum_{i=1}^n (x_i^2 - 2\bar{x}x_i + \bar{x}^2) = \sum x_i^2 - 2\bar{x}\sum x_i + n\bar{x}^2$$
  Substituting $\bar{x} = \frac{\sum x_i}{n}$:
  $$= \sum x_i^2 - 2\frac{(\sum x_i)^2}{n} + \frac{(\sum x_i)^2}{n} = \sum x_i^2 - \frac{(\sum x_i)^2}{n}$$
  Dividing through by $n$:
  $$\sigma_x^2 = \frac{\sum x_i^2}{n} - \left(\frac{\sum x_i}{n}\right)^2$$
  $$\sigma_x = \sqrt{\frac{\sum x_i^2}{n} - \bar{x}^2}$$

## 2. Walkthrough of Review Quiz 1 (Slide 30)

**Problem:** Find the RMS contrast of the $2 \times 2$ image:
$$I = \begin{bmatrix} 10 & 20 \\ 30 & 40 \end{bmatrix}, \quad n = 4 \text{ pixels}, \quad x = [10, 20, 30, 40]$$

### Solution Method 1:

1.  **Mean ($\bar{x}$):**
    $$\bar{x} = \frac{10 + 20 + 30 + 40}{4} = \frac{100}{4} = 25$$
2.  **Deviations squared:**
    $$(10 - 25)^2 = (-15)^2 = 225$$
    $$(20 - 25)^2 = (-5)^2 = 25$$
    $$(30 - 25)^2 = (5)^2 = 25$$
    $$(40 - 25)^2 = (15)^2 = 225$$
3.  **Variance ($\sigma_x^2$):**
    $$\sigma_x^2 = \frac{225 + 25 + 25 + 225}{4} = \frac{500}{4} = 125$$
4.  **RMS Contrast:**
    $$\sigma_x = \sqrt{125} = 5\sqrt{5} \approx \mathbf{11.18}$$

### Solution Method 2:

1.  **Sum of squares:**
    $$\sum x_i^2 = 10^2 + 20^2 + 30^2 + 40^2 = 100 + 400 + 900 + 1600 = 3000$$
2.  **Average of squares:**
    $$\frac{\sum x_i^2}{n} = \frac{3000}{4} = 750$$
3.  **Square of the mean:**
    $$\bar{x}^2 = \left(\frac{100}{4}\right)^2 = 25^2 = 625$$
4.  **Variance & RMS Contrast:**
    $$\sigma_x^2 = 750 - 625 = 125 \implies \sigma_x = \sqrt{125} \approx \mathbf{11.18}$$

# Part 4: Image Quality Metrics (RMSE, PSNR)

## 1. Definitions & Formulas (Slides 32–35)

For a reference image $f(x, y)$ and a degraded image $g(x, y)$ of size $M \times N$:
$$\text{MSE} = \frac{1}{MN} \sum_{x=1}^M \sum_{y=1}^N [f(x, y) - g(x, y)]^2$$
$$\text{RMSE} = \sqrt{\text{MSE}}$$
$$\text{PSNR (dB)} = 10 \log_{10} \left( \frac{\text{MAX}_I^2}{\text{MSE}} \right) = 20 \log_{10} \left( \frac{\text{MAX}_I}{\text{RMSE}} \right)$$
For 8-bit images, $\text{MAX}_I = 255$.

### Perceived Quality Rule-of-Thumb Table (Slide 35):

|        PSNR (dB)        | Perceived Visual Quality | Interpretation                            |
| :---------------------: | :----------------------: | :---------------------------------------- |
|  **$> 40\text{ dB}$**   |        Excellent         | Differences are virtually imperceptible.  |
| **$30 - 40\text{ dB}$** |           Good           | Slight differences, generally acceptable. |
| **$20 - 30\text{ dB}$** |           Fair           | Noticeable degradation.                   |
|  **$< 20\text{ dB}$**   |           Poor           | Severe distortion, unacceptable quality.  |

### Maximum Theoretical PSNR for Smallest Non-Zero Error ($\text{MSE} = 1$):

- **8-bit:** $20 \log_{10}(255 / 1) \approx \mathbf{48.13\text{ dB}}$
- **10-bit:** $20 \log_{10}(1023 / 1) \approx \mathbf{60.20\text{ dB}}$
- **12-bit:** $20 \log_{10}(4095 / 1) \approx \mathbf{72.25\text{ dB}}$
- **16-bit:** $20 \log_{10}(65535 / 1) \approx \mathbf{96.33\text{ dB}}$

# Part 5: Pattern Matching & Distance Metrics

```
                    PATTERN MATCHING METRICS
      --------------------------------------------------
      |                        |                       |
   L1 Norm                  L2 Norm            Correlation / Angle
  SAD (Manhattan)        SSD (Euclidean)         ZNCC (Cosine Sim)
      |                        |                       |
   Zero-Mean:               Zero-Mean:            Inherently
  ZSAD (b-invariant)       ZSSD (b-invariant)    Affine-Invariant (a, b)
```

## 1. SAD and SSD (Slides 39–43)

Let $I_1(k, l)$ be a template of size $m \times n$, and $I_2(i+k, j+l)$ be the candidate patch in the target image.

### Sum of Absolute Differences (SAD) — $L_1$ Norm / Manhattan Distance:

$$\text{SAD}(i, j) = \sum_{k=0}^{m-1} \sum_{l=0}^{n-1} |I_1(k, l) - I_2(i+k, j+l)|$$

### Sum of Squared Differences (SSD) — Squared $L_2$ Norm / Euclidean Distance:

$$\text{SSD}(i, j) = \sum_{k=0}^{m-1} \sum_{l=0}^{n-1} [I_1(k, l) - I_2(i+k, j+l)]^2 = mn \times \text{MSE}$$

### Geometric Interpretation of $L_1$ vs $L_2$ Equidistance Contours (Slide 42):

- $L_1$ distance form: $|x| + |y| = d \implies$ produces a **rotated square (diamond)** contour.
- $L_2$ distance form: $\sqrt{x^2 + y^2} = d \implies$ produces a **perfect circle**.

---

## 2. Illumination Limitations & Zero-Mean Extensions (Slides 43, 51)

Under an affine illumination change where all pixel intensities shift by gain $a$ and offset $b$:
$$I'(x, y) = a \cdot I(x, y) + b$$

- Standard SAD and SSD fail completely because additive bias $b$ is accumulated across all pixels, causing large errors even for structurally identical patterns.

### Zero-Mean Extensions (ZSAD & ZSSD):

By subtracting the patch mean before taking differences:
$$\text{ZSAD}(i, j) = \sum_{k=0}^{m-1} \sum_{l=0}^{n-1} \Big| [I_1(k, l) - \bar{I}_1] - [I_2(i+k, j+l) - \bar{I}_2] \Big|$$
$$\text{ZSSD}(i, j) = \sum_{k=0}^{m-1} \sum_{l=0}^{n-1} \Big( [I_1(k, l) - \bar{I}_1] - [I_2(i+k, j+l) - \bar{I}_2] \Big)^2$$

- **Advantage:** Both ZSAD and ZSSD are **invariant to additive lighting shifts** ($I' = I + b$).
- **Limitation:** They remain sensitive to multiplicative/contrast scale changes ($a \neq 1$).

# Part 6: Zero-Mean Normalized Cross-Correlation (ZNCC)

## 1. Statistical & Vector Formulations (Slides 45–47)

### Statistical Formula:

$$r_{\text{ZNCC}} = \frac{\sigma_{xy}}{\sigma_x \sigma_y} = \frac{\sum_{k=1}^n (x_k - \bar{x})(y_k - \bar{y})}{\sqrt{\sum_{k=1}^n (x_k - \bar{x})^2} \sqrt{\sum_{k=1}^n (y_k - \bar{y})^2}}$$

### Vector Geometry (Exercise 5, Slide 46):

Define centered difference vectors $\mathbf{u}$ and $\mathbf{v} \in \mathbb{R}^n$:
$$\mathbf{u} = \begin{bmatrix} x_1 - \bar{x} \\ x_2 - \bar{x} \\ \vdots \\ x_n - \bar{x} \end{bmatrix}, \quad \mathbf{v} = \begin{bmatrix} y_1 - \bar{y} \\ y_2 - \bar{y} \\ \vdots \\ y_n - \bar{y} \end{bmatrix}$$
Then:
$$r = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|} = \cos\theta$$
Where:

- $\mathbf{u} \cdot \mathbf{v} = \sum_{k=1}^n (x_k - \bar{x})(y_k - \bar{y})$
- $\|\mathbf{u}\| = \sqrt{\sum_{k=1}^n (x_k - \bar{x})^2}$
- $\|\mathbf{v}\| = \sqrt{\sum_{k=1}^n (y_k - \bar{y})^2}$
- $\theta$ is the angle between the two vectors in $n$-dimensional space.

### Key Mathematical Bounds:

$$\mathbf{-1 \le \text{ZNCC} \le +1}$$

- $\text{ZNCC} = +1 \iff \theta = 0^\circ$ (Perfect positive correlation; identical pattern shape up to positive affine scaling).
- $\text{ZNCC} = 0 \iff \theta = 90^\circ$ (Orthogonal; zero linear relationship).
- $\text{ZNCC} = -1 \iff \theta = 180^\circ$ (Perfect inverse correlation; photographic negative).

# Part 7: Structural Similarity Index (SSIM)

## 1. The SSIM Formula & Components (Slide 52)

Developed by Wang and Bovik (2004), SSIM matches human visual perception by measuring three separate attributes between images $\mathbf{x}$ and $\mathbf{y}$:

$$\text{SSIM}(\mathbf{x}, \mathbf{y}) = [l(\mathbf{x}, \mathbf{y})] \cdot [c(\mathbf{x}, \mathbf{y})] \cdot [s(\mathbf{x}, \mathbf{y})]$$

$$\text{SSIM}(\mathbf{x}, \mathbf{y}) = \left( \frac{2\mu_x\mu_y + C_1}{\mu_x^2 + \mu_y^2 + C_1} \right) \cdot \left( \frac{2\sigma_x\sigma_y + C_2}{\sigma_x^2 + \sigma_y^2 + C_2} \right) \cdot \left( \frac{\sigma_{xy} + C_3}{\sigma_x\sigma_y + C_3} \right)$$

- **Luminance Comparison $l(\mathbf{x}, \mathbf{y})$:** Compares mean brightness ($\mu_x, \mu_y$).
- **Contrast Comparison $c(\mathbf{x}, \mathbf{y})$:** Compares intensity standard deviations ($\sigma_x, \sigma_y$).
- **Structure Comparison $s(\mathbf{x}, \mathbf{y})$:** Evaluates correlation after removing mean and variance ($\sigma_{xy} / \sigma_x\sigma_y$ is the correlation coefficient, matching ZNCC!).
- **Stability Constants:** $C_1, C_2, C_3 > 0$ prevent division by zero in near-flat or black regions.

---

## 2. Derivation of SSIM Terms from AM and GM (Slides 54–55)

The mathematical foundation behind both the luminance and contrast terms comes from the **Ratio of Geometric Mean to Arithmetic Mean**:

For two positive numbers $X$ and $Y$:

- **Arithmetic Mean:** $\text{AM} = \frac{X + Y}{2}$
- **Geometric Mean:** $\text{GM} = \sqrt{XY}$

### AM–GM Inequality Proof:

$$(\sqrt{X} - \sqrt{Y})^2 \ge 0$$
$$X - 2\sqrt{XY} + Y \ge 0 \implies \frac{X + Y}{2} \ge \sqrt{XY} \implies \mathbf{\text{AM} \ge \text{GM}}$$
Therefore:
$$\frac{\text{GM}}{\text{AM}} = \frac{\sqrt{XY}}{\frac{X + Y}{2}} = \frac{2\sqrt{XY}}{X + Y} \le 1$$

- $\frac{\text{GM}}{\text{AM}} = 1$ if and only if $X = Y$.

### Deriving the SSIM Terms (Slide 55):

- Let $X = \mu_x^2$ and $Y = \mu_y^2$:
  $$\frac{\text{GM}}{\text{AM}} = \frac{2\sqrt{\mu_x^2 \mu_y^2}}{\mu_x^2 + \mu_y^2} = \mathbf{\frac{2\mu_x\mu_y}{\mu_x^2 + \mu_y^2}} \quad \text{(Luminance Term!)}$$
- Let $X = \sigma_x^2$ and $Y = \sigma_y^2$:
  $$\frac{\text{GM}}{\text{AM}} = \frac{2\sqrt{\sigma_x^2 \sigma_y^2}}{\sigma_x^2 + \sigma_y^2} = \mathbf{\frac{2\sigma_x\sigma_y}{\sigma_x^2 + \sigma_y^2}} \quad \text{(Contrast Term!)}$$

## 3. Harmonic Mean (HM) and the Full Inequality (Slide 57)

- **Harmonic Mean Definition:**
  $$\text{HM} = \frac{2}{\frac{1}{x} + \frac{1}{y}} = \frac{2xy}{x + y}$$
- **Physical Example (Slide 57):** Average speed over a round-trip route of distance $l$ out at speed $v_1$ and return at speed $v_2$:
  $$\bar{v} = \frac{\text{Total Distance}}{\text{Total Time}} = \frac{2l}{\frac{l}{v_1} + \frac{l}{v_2}} = \frac{2v_1 v_2}{v_1 + v_2} = \text{Harmonic Mean of } (v_1, v_2)$$
- **Connection to GM and AM:**
  $$\text{HM} = \frac{2xy}{x + y} = \frac{(\sqrt{xy})^2}{\frac{x + y}{2}} = \frac{\text{GM}^2}{\text{AM}} = \left( \frac{\text{GM}}{\text{AM}} \right) \cdot \text{GM}$$
  Because $\frac{\text{GM}}{\text{AM}} \le 1$, it directly follows that:
  $$\mathbf{\text{AM} \ge \text{GM} \ge \text{HM}}$$

## 2. Seven Core Challenges in Pattern Matching (Slide 58)

1.  **Changes of Image Intensities:** Direct sunlight, shadows, or automatic camera gain alter pixel values (handled by ZNCC or ZSAD).
2.  **Occlusion Problem:** An intervening foreground obstacle covers part of the template, altering squared errors across the patch.
3.  **Rotations of a Pattern:** Standard 2D sliding templates assume axis-aligned patterns. Any rotation breaks row-column alignment.
4.  **Scale Changes:** Distance changes between camera and scene cause the target to appear larger or smaller than the fixed template size.
5.  **Perspective Distortion:** Non-frontal viewing angles introduce homographic/keystone transformations that warp square features into general quadrilaterals.
6.  **Changes of Focus Levels:** Out-of-focus blur removes the high-frequency components that cross-correlation relies upon.
7.  **The Aperture Problem (Insufficient Gradient Directions):** If a local template contains only a straight edge (a 1D gradient), motion or matches perpendicular to the gradient can be detected, but movement along the parallel edge is ambiguous and cannot be localized. Point features (corners with gradients in at least two orthogonal directions) are required for unique pattern matching.
