## 1. Color Filter Array (CFA) & Demosaicing

### 1.1 The Physical Problem

Digital image sensors (CCD and CMOS) are inherently **monochromatic** (panchromatic): each photodiode simply accumulates incoming photons and generates a charge proportional to total radiant energy, without differentiating between wavelengths.

To produce a color image without using three separate physical sensor chips and an optical beam-splitter, a **Color Filter Array (CFA)** is placed directly over the pixel lattice. The most ubiquitous CFA is the **Bayer Filter Pattern**, which uses a $2 \times 2$ repeating mosaic:
$$\begin{bmatrix} R & G \\ G & B \end{bmatrix}$$

- **50% Green, 25% Red, 25% Blue:** Green pixels are twice as dense because the Human Visual System’s (HVS) photopic luminous efficiency peaks near $555\text{ nm}$ (green band). The human eye relies primarily on green wavelengths to resolve fine spatial detail and luminance.
- **Demosaicing (CFA Interpolation):** The computational process of reconstructing the two missing color channels at every pixel position from the surrounding mosaic samples to yield a full 3-channel RGB image.
- **RAW vs. Firmware Interpolation:** A digital camera’s **RAW** format records the unprocessed sensor readings straight from the CFA. Saving in RAW allows offline, higher-order demosaicing algorithms on a computer rather than relying on the camera's real-time hardware ASIC.

---

### 1.2 Mathematical Foundations: 1-D Linear Interpolation

Linear interpolation estimates an intermediate value $v_x$ between two known points $v_1$ and $v_2$ via an inverse-distance weighted average.

```
       v1 o
          | \
          |   \
          |     \  vx
          |       o-------
          |       |      |
          |       |      o v2
          |       |      |
      ----+-------+------+----
          |<--m-->|<--n->|
             x1       x      x2
```

Let the distance between $x_1$ and $x$ be $m$, and between $x$ and $x_2$ be $n$. The total interval is $m + n$:

$$v_x = \frac{n}{m+n} v_1 + \frac{m}{m+n} v_2 = w \cdot v_1 + (1 - w) \cdot v_2 \quad \text{where } w = \frac{n}{m+n}$$

> **Notice the inverse proportionality:** The closer $x$ is to $v_1$ (smaller $m$), the larger the weight assigned to $v_1$ (weight is proportional to $n$).

#### Numerical Example:

Let $v_1 = 40$ at $x_1 = 0$, and $v_2 = 120$ at $x_2 = 10$. Find $v_x$ at $x = 2.5$.

- $m = 2.5 - 0 = 2.5$
- $n = 10 - 2.5 = 7.5$
- $v_x = \frac{7.5}{10}(40) + \frac{2.5}{10}(120) = 0.75(40) + 0.25(120) = 30 + 30 = 60$.

### 1.3 Detailed Solution to Exercise 1: 2-D CFA Interpolation

#### Problem Statement:

In a Bayer array, a "virtual pixel" $P_X$ is located inside a cell bounded by the surrounding physical CCD cells. By extending 1-D linear interpolation into 2-D (bilinear interpolation), derive the formulas for:
$$P_{X\_\text{Green}} = \frac{G_7 + G_{10}}{2}$$
$$P_{X\_\text{Red}} = \frac{9 R_{11} + 3 R_3 + 3 R_9 + R_1}{16}$$
$$P_{X\_\text{Blue}} = \frac{9 B_6 + 3 B_8 + 3 B_{14} + B_{16}}{16}$$

```
                Column Grid (spacing d = 1)
              Col 1    Col 2    Col 3    Col 4
    Row 1:   [ R1  ]  [ G2  ]  [ R3  ]  [ G4  ]
    Row 2:   [ G5  ]  [ B6  ]  [ G7  ]  [ B8  ]
                        \        |
                         \   (Px)| (at row 2.5, col 2.5)
                          \      |
    Row 3:   [ R9  ]  [ G10 ]  [ R11 ]  [ G12 ]
    Row 4:   [ G13 ]  [ B14 ]  [ G15 ]  [ B16 ]
```

#### Step-by-Step Derivations:

#### 1. Green Channel ($P_{X\_\text{Green}}$):

- Looking at the mosaic around $P_X$, the two closest green sensors are $G_7$ (at Row 2, Col 3) and $G_{10}$ (at Row 3, Col 2).
- The virtual pixel $P_X$ is located at the center intersection (Row 2.5, Col 2.5).
- The Euclidean distance from $P_X$ to $G_7$ is:
  $$\Delta r = 2.5 - 2 = 0.5, \quad \Delta c = 3 - 2.5 = 0.5 \implies d_1 = \sqrt{0.5^2 + 0.5^2} = \sqrt{0.5}$$
- The Euclidean distance from $P_X$ to $G_{10}$ is:
  $$\Delta r = 3 - 2.5 = 0.5, \quad \Delta c = 2.5 - 2 = 0.5 \implies d_2 = \sqrt{0.5^2 + 0.5^2} = \sqrt{0.5}$$
- Since $d_1 = d_2$, the weights are equal ($w = 0.5$):
  $$P_{X\_\text{Green}} = \frac{G_7 + G_{10}}{2}$$

---

#### 2. Red Channel ($P_{X\_\text{Red}}$):

The four surrounding red sensors are located at:

- $R_1$: Row 1, Col 1
- $R_3$: Row 1, Col 3
- $R_9$: Row 3, Col 1
- $R_{11}$: Row 3, Col 3

The virtual pixel $P_X$ is located at $(r = 2.5, c = 2.5)$.
Notice that $R$ samples form a grid with spacing $\Delta = 2$ units between adjacent red sensors:

- In the vertical direction: Row 1 is at $y = 1$, Row 3 is at $y = 3$. The point $y = 2.5$ divides the interval $[1, 3]$ into:
  - Distance from Row 1: $m_y = 2.5 - 1 = 1.5$
  - Distance from Row 3: $n_y = 3 - 2.5 = 0.5$
  - Normalized weights along $y$:
    $$w_{y,\text{Row } 3} = \frac{m_y}{m_y + n_y} = \frac{1.5}{2.0} = \frac{3}{4}, \quad w_{y,\text{Row } 1} = \frac{n_y}{m_y + n_y} = \frac{0.5}{2.0} = \frac{1}{4}$$

- In the horizontal direction: Col 1 is at $x = 1$, Col 3 is at $x = 3$. The point $x = 2.5$ divides the interval $[1, 3]$ into:
  - Distance from Col 1: $m_x = 2.5 - 1 = 1.5$
  - Distance from Col 3: $n_x = 3 - 2.5 = 0.5$
  - Normalized weights along $x$:
    $$w_{x,\text{Col } 3} = \frac{m_x}{m_x + n_x} = \frac{1.5}{2.0} = \frac{3}{4}, \quad w_{x,\text{Col } 1} = \frac{n_x}{m_x + n_x} = \frac{0.5}{2.0} = \frac{1}{4}$$

By 2-D separable bilinear interpolation, the weight for any corner is the product of its 1-D directional weights ($W(x, y) = w_x \cdot w_y$):

- **Weight for $R_{11}$ (Row 3, Col 3):**
  $$W_{11} = w_{y,\text{Row } 3} \times w_{x,\text{Col } 3} = \frac{3}{4} \times \frac{3}{4} = \frac{\mathbf{9}}{\mathbf{16}}$$
- **Weight for $R_3$ (Row 1, Col 3):**
  $$W_3 = w_{y,\text{Row } 1} \times w_{x,\text{Col } 3} = \frac{1}{4} \times \frac{3}{4} = \frac{\mathbf{3}}{\mathbf{16}}$$
- **Weight for $R_9$ (Row 3, Col 1):**
  $$W_9 = w_{y,\text{Row } 3} \times w_{x,\text{Col } 1} = \frac{3}{4} \times \frac{1}{4} = \frac{\mathbf{3}}{\mathbf{16}}$$
- **Weight for $R_1$ (Row 1, Col 1):**
  $$W_1 = w_{y,\text{Row } 1} \times w_{x,\text{Col } 1} = \frac{1}{4} \times \frac{1}{4} = \frac{\mathbf{1}}{\mathbf{16}}$$

Summing these contributions yields the exact formula from the slide:
$$P_{X\_\text{Red}} = \frac{9 R_{11} + 3 R_3 + 3 R_9 + 1 R_1}{16}$$

---

#### 3. Blue Channel ($P_{X\_\text{Blue}}$):

The surrounding blue sensors are located at:

- $B_6$: Row 2, Col 2
- $B_8$: Row 2, Col 4
- $B_{14}$: Row 4, Col 2
- $B_{16}$: Row 4, Col 4

The virtual pixel $P_X$ is at $(r = 2.5, c = 2.5)$.

- Along the vertical direction between Row 2 and Row 4:
  - Distance to Row 2: $0.5 \implies \text{weight for Row 2} = \frac{2 - 0.5}{2} = \frac{1.5}{2} = \frac{3}{4}$
  - Distance to Row 4: $1.5 \implies \text{weight for Row 4} = \frac{0.5}{2} = \frac{1}{4}$
- Along the horizontal direction between Col 2 and Col 4:
  - Distance to Col 2: $0.5 \implies \text{weight for Col 2} = \frac{2 - 0.5}{2} = \frac{1.5}{2} = \frac{3}{4}$
  - Distance to Col 4: $1.5 \implies \text{weight for Col 4} = \frac{0.5}{2} = \frac{1}{4}$

Computing the product weights:

- **Weight for $B_6$ (Row 2, Col 2):** $\frac{3}{4} \times \frac{3}{4} = \frac{\mathbf{9}}{\mathbf{16}}$
- **Weight for $B_8$ (Row 2, Col 4):** $\frac{3}{4} \times \frac{1}{4} = \frac{\mathbf{3}}{\mathbf{16}}$
- **Weight for $B_{14}$ (Row 4, Col 2):** $\frac{1}{4} \times \frac{3}{4} = \frac{\mathbf{3}}{\mathbf{16}}$
- **Weight for $B_{16}$ (Row 4, Col 4):** $\frac{1}{4} \times \frac{1}{4} = \frac{\mathbf{1}}{\mathbf{16}}$

Thus:
$$P_{X\_\text{Blue}} = \frac{9 B_6 + 3 B_8 + 3 B_{14} + 1 B_{16}}{16}$$

### 1.4 Detailed Solution to Exercise 2: Adaptive/Gradient-Based CFA Interpolation

#### Problem Statement:

To interpolate the missing green value at blue position $B_{22}$:
$$V = |G_{12} - G_{32}| \quad \text{// Vertical gradient}$$
$$H = |G_{21} - G_{23}| \quad \text{// Horizontal gradient}$$

$$
\begin{aligned}
&\text{\textbf{if} } V > H + \epsilon \text{ \textbf{then} } G_{22} = \frac{G_{21} + G_{23}}{2} \\
&\text{\textbf{else if} } H > V + \epsilon \text{ \textbf{then} } G_{22} = \frac{G_{12} + G_{32}}{2} \\
&\text{\textbf{else} } G_{22} = \frac{G_{12} + G_{32} + G_{21} + G_{23}}{4}
\end{aligned}
$$

_(where $\epsilon$ is a small scalar threshold)._  
**Explain the benefit of this approach compared to primitive averaging.**

```
                     G12 (above)
                      |
        G21 (left) -- B22 -- G23 (right)
                      |
                     G32 (below)
```

#### Detailed Explanation & Benefits:

1.  **Gradient Measures Spatial Discontinuity:**
    - $V = |G_{12} - G_{32}|$ computes the absolute rate of change in the **vertical** direction. A high value of $V$ indicates a sharp transition or edge running horizontally between Row 1 and Row 3.
    - $H = |G_{21} - G_{23}|$ computes the rate of change in the **horizontal** direction. A high value of $H$ indicates an edge running vertically between Col 1 and Col 3.
2.  **Edge-Directed Smoothing (Interpolate ALONG edges, never ACROSS them):**
    - **Case 1 ($V > H + \epsilon$):** The vertical gradient is significantly larger than the horizontal gradient. This means a sharp horizontal edge exists across the vertical axis. Averaging vertically ($G_{12}$ and $G_{32}$) would blend two completely different color regions, causing blurring and false colors. Therefore, the algorithm interpolates **horizontally** along the edge where variation is low: $G_{22} = \frac{G_{21} + G_{23}}{2}$.
    - **Case 2 ($H > V + \epsilon$):** A sharp vertical edge exists. The algorithm interpolates **vertically** along the edge: $G_{22} = \frac{G_{12} + G_{32}}{2}$.
    - **Case 3 ($|V - H| \le \epsilon$):** The region is flat (or equally smooth in both directions), so it safely performs a 4-neighbor isotropic average: $G_{22} = \frac{G_{12} + G_{32} + G_{21} + G_{23}}{4}$.
3.  **Elimination of "Zipper Artifacts":**
    Primitive non-adaptive averaging blurs color channels across high-contrast edges. Because different channels sample different spatial points, this cross-edge blur creates alternating false color fringes resembling a zipper along boundaries. Edge-adaptive interpolation prevents this by respecting image gradients.

## 2. RGB Color Model & Distance Metrics

### 2.1 RGB Cube Fundamentals

- **Additive Model:** Colors are generated by emitting light. Combining full red, green, and blue intensities yields white: $(1, 1, 1)$.
- **Subtractive (CMY/YMC) Model:** Used for printing and inks. Dyes absorb (subtract) specific wavelengths from incident white light:
  $$\begin{bmatrix} C \\ M \\ Y \end{bmatrix} = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix} - \begin{bmatrix} R \\ G \\ B \end{bmatrix}$$
- **Achromatic Diagonal (Grayscale Line):** Connects the origin $(0, 0, 0)$ (black) to $(1, 1, 1)$ (white), where $R = G = B$.

---

### 2.2 Luminance Conversion: `rgb2gray`

When converting an RGB image to grayscale, human perception does not weigh the three primary colors equally. MATLAB’s `rgb2gray` implements the standard NTSC/YIQ luminance equation:

$$Y = 0.299\,R + 0.587\,G + 0.114\,B$$

- Green contributes $\sim 59\%$ of perceived luminance.
- Red contributes $\sim 30\%$.
- Blue contributes only $\sim 11\%$.

### 2.3 Detailed Solution to Exercise 3: Distance Metrics in RGB Space

Given two color vectors in RGB space:
$$\mathbf{C}_1 = (r_1, g_1, b_1)^T \quad \text{and} \quad \mathbf{C}_2 = (r_2, g_2, b_2)^T$$
Define the difference vector as:
$$\Delta \mathbf{C} = \mathbf{C}_1 - \mathbf{C}_2 = (\Delta r, \Delta g, \Delta b)^T = (r_1 - r_2, \, g_1 - g_2, \, b_1 - b_2)^T$$

```
                           B
                           ^
                           |    C2 (r2, g2, b2)
                           |   /
                           |  /  Euclidean Distance (L2)
                           | /
                           |/____ C1 (r1, g1, b1)
                           +-------------------> G
                          /
                         /
                        v R
```

#### 1. SAD (Sum of Absolute Differences) / $L_1$ Norm / Manhattan Distance:

Measures the sum of rectilinear steps across each axis:
$$\text{SAD}(\mathbf{C}_1, \mathbf{C}_2) = \|\mathbf{C}_1 - \mathbf{C}_2\|_1 = |r_1 - r_2| + |g_1 - g_2| + |b_1 - b_2|$$

#### 2. SSD (Sum of Squared Differences):

Accumulates squared errors:
$$\text{SSD}(\mathbf{C}_1, \mathbf{C}_2) = (r_1 - r_2)^2 + (g_1 - g_2)^2 + (b_1 - b_2)^2$$

#### 3. ED (Euclidean Distance) / $L_2$ Norm:

The straight-line geometric distance in 3D Euclidean space:
$$\text{ED}(\mathbf{C}_1, \mathbf{C}_2) = \|\mathbf{C}_1 - \mathbf{C}_2\|_2 = \sqrt{\text{SSD}} = \sqrt{(r_1 - r_2)^2 + (g_1 - g_2)^2 + (b_1 - b_2)^2}$$

#### 4. MAD (Maximum of Absolute Differences) / $L_\infty$ Norm / Chebyshev Distance:

Determined solely by the single color channel with the worst mismatch:
$$\text{MAD}(\mathbf{C}_1, \mathbf{C}_2) = \|\mathbf{C}_1 - \mathbf{C}_2\|_\infty = \max\Big(|r_1 - r_2|, \, |g_1 - g_2|, \, |b_1 - b_2|\Big)$$

---

#### Comprehensive Numerical Example:

Let Color 1 be an orange tone: $\mathbf{C}_1 = (240, 130, 20)$  
Let Color 2 be an olive tone: $\mathbf{C}_2 = (200, 150, 60)$

1.  **Component Differences:**
    - $\Delta r = |240 - 200| = 40$
    - $\Delta g = |130 - 150| = 20$
    - $\Delta b = |20 - 60| = 40$
2.  **SAD ($L_1$):**
    $$\text{SAD} = 40 + 20 + 40 = \mathbf{100}$$
3.  **SSD:**
    $$\text{SSD} = 40^2 + 20^2 + 40^2 = 1600 + 400 + 1600 = \mathbf{3600}$$
4.  **ED ($L_2$):**
    $$\text{ED} = \sqrt{3600} = \mathbf{60.0}$$
5.  **MAD ($L_\infty$):**
    $$\text{MAD} = \max(40, 20, 40) = \mathbf{40}$$

## 3. The HSV (HSI) Color Model

### 3.1 Intuition & Perceptual Motivation

- **Hue ($H$):** Represents dominant wavelength (the actual color attribute, such as "red", "cyan", "purple"). It is an angular measure on a circular wheel: $0^\circ \le H < 360^\circ$ (or normalized $H \in [0, 1]$).
- **Saturation ($S$):** The purity of the color, or how much white light is mixed in. $S=1$ is a pure spectral color; $S=0$ is a shade of gray.
- **Intensity ($I$) / Value ($V$):** The brightness / light energy.
  - $I = \frac{R + G + B}{3}$ (average intensity, forming a double hexcone).
  - $V = \max(R, G, B)$ (peak brightness, forming a single hexcone).

---

### 3.2 RGB to HSI Mathematical Formulation

For $R, G, B \in [0, 1]$:

$$I = \frac{1}{3}(R + G + B)$$

$$S = 1 - \frac{3}{R + G + B}\min(R, G, B) \quad (\text{for } R+G+B > 0; \ S = 0 \text{ if } R=G=B=0)$$

$$H = \begin{cases} \theta & \text{if } B \le G \\ 360^\circ - \theta & \text{if } B > G \end{cases}$$

$$\theta = \arccos \left( \frac{\frac{1}{2}\big[(R - G) + (R - B)\big]}{\sqrt{(R - G)^2 + (R - B)(G - B)}} \right)$$

---

### 3.3 Detailed Solution to Exercise 4: Hue and Saturation

#### Part 1: Derive Hue Angles $\theta$ for the Primary and Secondary Colors

Let us evaluate each color vector through the mathematical formula:

##### 1. Pure Red: $(R, G, B) = (1, 0, 0)$

- $R - G = 1 - 0 = 1$
- $R - B = 1 - 0 = 1$
- $G - B = 0 - 0 = 0$
- Numerator: $\frac{1}{2}(1 + 1) = 1$
- Denominator: $\sqrt{1^2 + (1)(0)} = \sqrt{1} = 1$
- $\theta = \arccos(1/1) = \arccos(1) = 0^\circ$
- Since $B \le G$ ($0 \le 0$), $H = \theta = \mathbf{0^\circ}$.

##### 2. Pure Yellow: $(R, G, B) = (1, 1, 0)$

- $R - G = 1 - 1 = 0$
- $R - B = 1 - 0 = 1$
- $G - B = 1 - 0 = 1$
- Numerator: $\frac{1}{2}(0 + 1) = 0.5$
- Denominator: $\sqrt{0^2 + (1)(1)} = \sqrt{1} = 1$
- $\theta = \arccos(0.5) = 60^\circ$
- Since $B \le G$ ($0 \le 1$), $H = \theta = \mathbf{60^\circ}$.

##### 3. Pure Green: $(R, G, B) = (0, 1, 0)$

- $R - G = 0 - 1 = -1$
- $R - B = 0 - 0 = 0$
- $G - B = 1 - 0 = 1$
- Numerator: $\frac{1}{2}(-1 + 0) = -0.5$
- Denominator: $\sqrt{(-1)^2 + (0)(1)} = \sqrt{1} = 1$
- $\theta = \arccos(-0.5) = 120^\circ$
- Since $B \le G$ ($0 \le 1$), $H = \theta = \mathbf{120^\circ}$.

##### 4. Pure Cyan: $(R, G, B) = (0, 1, 1)$

- $R - G = 0 - 1 = -1$
- $R - B = 0 - 1 = -1$
- $G - B = 1 - 1 = 0$
- Numerator: $\frac{1}{2}(-1 + -1) = -1$
- Denominator: $\sqrt{(-1)^2 + (-1)(0)} = \sqrt{1} = 1$
- $\theta = \arccos(-1) = 180^\circ$
- Since $B \le G$ ($1 \le 1$), $H = \theta = \mathbf{180^\circ}$.

##### 5. Pure Blue: $(R, G, B) = (0, 0, 1)$

- $R - G = 0 - 0 = 0$
- $R - B = 0 - 1 = -1$
- $G - B = 0 - 1 = -1$
- Numerator: $\frac{1}{2}(0 + -1) = -0.5$
- Denominator: $\sqrt{0^2 + (-1)(-1)} = \sqrt{1} = 1$
- $\theta = \arccos(-0.5) = 120^\circ$
- **Crucial step:** Here $B > G$ ($1 > 0$). Therefore:
  $$H = 360^\circ - \theta = 360^\circ - 120^\circ = \mathbf{240^\circ}$$

##### 6. Pure Magenta: $(R, G, B) = (1, 0, 1)$

- $R - G = 1 - 0 = 1$
- $R - B = 1 - 1 = 0$
- $G - B = 0 - 1 = -1$
- Numerator: $\frac{1}{2}(1 + 0) = 0.5$
- Denominator: $\sqrt{1^2 + (0)(-1)} = \sqrt{1} = 1$
- $\theta = \arccos(0.5) = 60^\circ$
- Here $B > G$ ($1 > 0$). Therefore:
  $$H = 360^\circ - \theta = 360^\circ - 60^\circ = \mathbf{300^\circ}$$

#### Part 2: Find the Saturation along the Diagonal Line from $(0,0,0)$ to $(1,1,1)$

- Along the main diagonal connecting black to white, every point has equal color components:
  $$R = G = B = k \quad \text{where } k \in [0, 1]$$
- Substitute into the saturation formula:
  $$S = 1 - \frac{3}{R+G+B} \min(R, G, B) = 1 - \frac{3}{k + k + k} \cdot k = 1 - \frac{3}{3k} \cdot k = 1 - 1 = \mathbf{0}$$
- **Conclusion:** Saturation is identically **$0$** along the entire diagonal. This confirms that the diagonal represents the purely achromatic grayscale axis.

---

#### Part 3: Find the Saturation along the 12 Edges of the RGB Color Cube

The RGB cube has 12 distinct edges:

1.  **3 Edges emanating from Black $(0,0,0)$:**
    - From $(0,0,0)$ to $(1,0,0)$ (along Red axis): Here $G=0, B=0, R \in (0, 1]$.
      $$\min(R, G, B) = 0 \implies S = 1 - \frac{3}{R + 0 + 0}(0) = \mathbf{1}$$
    - From $(0,0,0)$ to $(0,1,0)$ (along Green axis): $\min = 0 \implies S = \mathbf{1}$.
    - From $(0,0,0)$ to $(0,0,1)$ (along Blue axis): $\min = 0 \implies S = \mathbf{1}$.
2.  **6 Outer Boundary Edges connecting Primaries to Secondaries:**
    - $(1,0,0) \to (1,1,0)$ (Red to Yellow): $B=0$, so $\min(R, G, B) = 0 \implies S = \mathbf{1}$.
    - $(0,1,0) \to (1,1,0)$ (Green to Yellow): $B=0 \implies \min = 0 \implies S = \mathbf{1}$.
    - $(0,1,0) \to (0,1,1)$ (Green to Cyan): $R=0 \implies \min = 0 \implies S = \mathbf{1}$.
    - $(0,0,1) \to (0,1,1)$ (Blue to Cyan): $R=0 \implies \min = 0 \implies S = \mathbf{1}$.
    - $(0,0,1) \to (1,0,1)$ (Blue to Magenta): $G=0 \implies \min = 0 \implies S = \mathbf{1}$.
    - $(1,0,0) \to (1,0,1)$ (Red to Magenta): $G=0 \implies \min = 0 \implies S = \mathbf{1}$.
    - _Across all these 6 edges, at least one component remains 0, so $S = 1$ everywhere._
3.  **3 Edges converging to White $(1,1,1)$:**
    - From Yellow $(1,1,0)$ to White $(1,1,1)$: Here $R=1, G=1$, while $B$ varies from $0 \to 1$.
      $$S(B) = 1 - \frac{3}{1 + 1 + B}\min(1, 1, B) = 1 - \frac{3B}{2 + B} = \frac{2 - 2B}{2 + B}$$
      - At Yellow ($B=0$): $S = \frac{2}{2} = 1$.
      - At White ($B=1$): $S = \frac{0}{3} = 0$.
      - _Saturation drops monotonically from $1$ down to $0$._
    - From Cyan $(0,1,1)$ to White $(1,1,1)$: $G=1, B=1$, while $R$ varies from $0 \to 1$.
      $$S(R) = \frac{2 - 2R}{2 + R} \quad (\text{drops monotonically from } 1 \to 0)$$
    - From Magenta $(1,0,1)$ to White $(1,1,1)$: $R=1, B=1$, while $G$ varies from $0 \to 1$.
      $$S(G) = \frac{2 - 2G}{2 + G} \quad (\text{drops monotonically from } 1 \to 0)$$

### 3.4 Detailed Solution to Exercise 5: Negative Color (Thai National Flag)

#### Problem Statement:

The Thai flag consists of three stripe colors:

- Red: $(1, 0, 0)$
- White: $(1, 1, 1)$
- Blue: $(0, 0, 1)$

```
   Thai Flag Stripes:
   -----------------------------------  RED
   -----------------------------------  WHITE
   ===================================  BLUE (Double width)
   -----------------------------------  WHITE
   -----------------------------------  RED
```

#### Question 1: What happens if ONLY the Hue of the flag is inverted?

- Inverting hue means shifting the hue angle by $180^\circ$ (the diametrically opposite complementary color):
  $$H' = (H + 180^\circ) \pmod{360^\circ} \quad \text{or in MATLAB: } H' = \text{mod}(H + 0.5, 1.0)$$
- **Red Stripe:**
  - Original: $H = 0^\circ, S = 1, I = 1/3$.
  - Inverted Hue: $H' = 0^\circ + 180^\circ = 180^\circ$.
  - $180^\circ$ corresponds to **Cyan**.
  - With $S=1$ and original $I=1/3$, the RGB values become $(0, 0.5, 0.5)$ (a dark cyan).
- **Blue Stripe:**
  - Original: $H = 240^\circ, S = 1, I = 1/3$.
  - Inverted Hue: $H' = (240^\circ + 180^\circ) \pmod{360^\circ} = 420^\circ - 360^\circ = 60^\circ$.
  - $60^\circ$ corresponds to **Yellow**.
  - With $S=1$ and original $I=1/3$, the RGB values become $(0.5, 0.5, 0)$ (a dark yellow/olive).
- **White Stripe:**
  - Original: $R=1, G=1, B=1 \implies S = 0$.
  - Because $S=0$, **Hue is undefined (a mathematical singularity)**.
  - Inverting an undefined angle leaves the saturation at $0$ and intensity at $1$.
  - **The white stripe remains completely unchanged (White)!**
- **Resulting Flag:** Cyan stripes on the outside, unchanged White middle borders, and a Yellow central stripe.

#### Question 2: How does the true negative of the flag image look?

The true photographic negative is defined in linear RGB space by taking the complement of every channel:
$$\mathbf{C}_{\text{neg}} = \mathbf{1} - \mathbf{C}_{\text{orig}} = (1 - R, \, 1 - G, \, 1 - B)$$

- **Red $(1, 0, 0)$:**
  $$\mathbf{C}_{\text{neg}} = (1 - 1, 1 - 0, 1 - 0) = (0, 1, 1) \implies \mathbf{Pure\ Cyan}$$
- **White $(1, 1, 1)$:**
  $$\mathbf{C}_{\text{neg}} = (1 - 1, 1 - 1, 1 - 1) = (0, 0, 0) \implies \mathbf{Pure\ Black}$$
- **Blue $(0, 0, 1)$:**
  $$\mathbf{C}_{\text{neg}} = (1 - 0, 1 - 0, 1 - 1) = (1, 1, 0) \implies \mathbf{Pure\ Yellow}$$

**Resulting Negative Flag:** Bright Cyan outer stripes, **Black** middle stripes, and a bright **Yellow** center stripe.

#### Question 3: What does the sum of the flag and its negative look like?

For every pixel $(x, y)$ in the entire image:

$$I_{\text{sum}}(x, y) = I_{\text{orig}}(x, y) + I_{\text{neg}}(x, y) = \begin{bmatrix} R \\ G \\ B \end{bmatrix} + \begin{bmatrix} 1 - R \\ 1 - G \\ 1 - B \end{bmatrix} = \begin{bmatrix} R + 1 - R \\ G + 1 - G \\ B + 1 - B \end{bmatrix} = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}$$

- Red: $(1, 0, 0) + (0, 1, 1) = (1, 1, 1)$ (White)
- White: $(1, 1, 1) + (0, 0, 0) = (1, 1, 1)$ (White)
- Blue: $(0, 0, 1) + (1, 1, 0) = (1, 1, 1)$ (White)

**Result:** A completely uniform, flat **Pure White** image everywhere.

### 3.5 Detailed Solution to Exercise 6: Evaluating Hue Differences

#### Problem Statement:

Hue values are normalized such that $\theta \in [0^\circ, 360^\circ)$ maps to $H \in [0, 1)$. We wish to evaluate the difference between two hue values $A$ and $B$.  
**Discuss whether it is appropriate to use $|A - B|$.**

```
                     0.0 (Red: 0 deg)
                     /      \
            (330 deg)        (30 deg)
            B = 0.917        A = 0.083
                     \      /
                    0.5 (Cyan: 180 deg)
```

#### Detailed Mathematical Analysis:

- **Why $|A - B|$ Fails:**
  Hue is an **angular (circular) coordinate**, not a linear Cartesian metric. The points $H = 0.0$ ($0^\circ$) and $H = 0.999$ ($359.6^\circ$) are visually near-identical shades of pure red separated by only $0.4^\circ$.
  However, the naive absolute difference calculates:
  $$\Delta_{\text{naive}} = |0.083 - 0.917| = |-0.834| = \mathbf{0.834}$$
  This formula incorrectly treats them as being nearly across the entire color space.
- **The Correct Metric (Circular Shortest Angular Distance):**
  The true distance between two angles on a circle is the shortest path along the circumference:

  $$\Delta_{\text{angular}}(A, B) = \min\Big(|A - B|, \, 1.0 - |A - B|\Big)$$

  Testing on $A = 0.083$ ($30^\circ$) and $B = 0.917$ ($330^\circ$):
  - $|A - B| = 0.834$
  - $1.0 - |A - B| = 1.0 - 0.834 = \mathbf{0.166}$ (which equals $\frac{60^\circ}{360^\circ}$)
  - $\Delta_{\text{correct}} = \min(0.834, 0.166) = \mathbf{0.166}$ (the true $60^\circ$ separation!).

### 4.1 Histogram Equalization in HSV Space (Slide 26)

- **Pitfall of RGB Equalization:** Applying histogram equalization to each channel ($R, G, B$) independently alters their relative ratios at every pixel:
  $$\frac{R'}{G'} \neq \frac{R}{G}$$
  This severely corrupts the original color tones, shifting hues and introducing heavy color distortion.
- **The HSV Solution:**
  1. Convert RGB $\to$ HSV.
  2. Leave Hue ($H$) **completely untouched**.
  3. Apply histogram equalization **only to the Value ($V$) or Intensity ($I$) channel**.
  4. Optionally apply a modest contrast stretch to Saturation ($S$) to prevent washed-out appearances.
  5. Convert HSV back to RGB.
     _Result:_ Contrast is enhanced while natural color balance and chromaticity remain intact.

---

### 4.2 Spatial Smoothing and Sharpening in HSV (Slides 27–28)

- **Problem:** Convolving a $5 \times 5$ averaging mask or a Laplacian sharpening mask across $R, G, B$ independently causes edge-color bleeding. Because primary channels have different edge transitions, sharpening independently causes rainbow-colored rings along edges.
- **Solution:** Filter **only the Intensity ($I$) plane**:
  $$I_{\text{sharp}} = I * \text{Laplacian}$$
  Then recombine with unchanged $H$ and $S$ channels. The edges appear crisp without chromatic fringing.

---

### 4.3 Skin-Color Detection & CAMSHIFT Tracking (Slides 29–32)

- **Bradski's Finding (1998):**
  Except for albinos, human skin across different ethnicities shares a surprisingly narrow, consistent **Hue range** (predominantly in the orange/red-yellow spectral band). Ethnic differences arise primarily from variations in melanin concentration, which alters **Intensity ($I$)** and **Saturation ($S$)**, while the underlying chromatic **Hue** remains virtually invariant.
- **Hue-Based Segmentation Rule:**
  A pixel belongs to skin if:
  $$H_{\min} \le H(x, y) \le H_{\max} \quad \text{AND} \quad S(x, y) \ge S_{\min}$$
- **Singularities / Failure Modes of Hue:**
  Hue becomes unstable or undefined under two conditions:
  1.  **Low Saturation ($S \approx 0$):** In near-gray, white, or black areas, the RGB vector sits close to the central diagonal. Minor sensor noise flips the angular calculation drastically.
  2.  **Extremely Low/High Intensity ($I \to 0$ or $I \to 1$):** At the tips of the color hexcone/bicone, the cross-sectional area shrinks to a point, making Hue calculation ill-conditioned.
- **CAMSHIFT (Continuously Adaptive Mean Shift):**
  1. Computes a 1-D Hue histogram of the target object.
  2. Computes the **Color Back-Projection** image, where each pixel value is its probability of belonging to the object given its Hue:
     $$P(x, y) = \text{Hist}(H(x, y))$$
  3. Uses Mean Shift to find the mode (center of mass) of the probability distribution.
  4. Dynamically resizes and rotates the tracking search window according to the 0th, 1st, and 2nd spatial moments:
     $$M_{00} = \sum_{x,y} P(x,y), \quad M_{10} = \sum_{x,y} x P(x,y), \quad M_{01} = \sum_{x,y} y P(x,y)$$
     $$\bar{x} = \frac{M_{10}}{M_{00}}, \quad \bar{y} = \frac{M_{01}}{M_{00}}$$

### 5.2 Safe RGB Colors & The Web-Safe Palette (Slides 36–38)

In early computer graphics hardware, display frame buffers were limited to 8 bits per pixel ($2^8 = 256$ colors). To prevent operating systems from dithering arbitrarily, a standardized subset called the **Web-Safe Palette** was established.

- Each primary channel ($R, G, B$) is allowed only **6 evenly spaced discrete intensity levels**:

$$\text{Levels} = \{0, \, 51, \, 102, \, 153, \, 204, \, 255\}$$
$$\text{In Hexadecimal: } \{\mathtt{00}, \, \mathtt{33}, \, \mathtt{66}, \, \mathtt{99}, \, \mathtt{CC}, \, \mathtt{FF}\}$$

- **Total Safe Colors:**
  $$N_{\text{safe}} = 6 \times 6 \times 6 = 6^3 = \mathbf{216\ colors}$$
- The remaining $256 - 216 = 40$ color indices in an 8-bit table were reserved by the operating system (Windows/Mac system UI colors).

#### Quantitative Ratio Problem (Slide 37):

Find the ratio between the number of safe colors and the total number of colors in a 24-bit RGB true-color space.

1.  Total 24-bit colors:
    $$2^{24} = (2^8)^3 = 256^3 = 16,777,216$$
2.  Total safe colors:
    $$6^3 = 216$$
3.  Ratio calculation:
    $$\text{Ratio} = \frac{6^3}{2^{24}} = \frac{216}{16,777,216} = \frac{27}{2,097,152} \approx 1.28746 \times 10^{-5}$$
    $$\mathbf{\text{Percentage}} \approx \mathbf{0.001288\%}$$
    _Exam Insight: The web-safe palette represents just over **one-thousandth of one percent** of the full 24-bit color spectrum._

### 5.3 Indexed RGB Images (Slides 39–41)

Instead of storing three bytes ($R, G, B$) for every pixel (which requires $M \times N \times 3$ bytes), an **Indexed Image** uses two separate data structures:

```
    IMAGE ARRAY (Size: M x N)                 COLOR MAP MATRIX (Size: 256 x 3)
      Indices: uint8 (0 to 255)                     Values: double [0.0, 1.0]
    +-----+-----+-----+-----+                      Index      R       G       B
    |  0  |  5  |  5  | 12  |                      +-----+--------+-------+-------+
    +-----+-----+-----+-----+                      |  0  | 0.0000 | 0.000 | 0.000 |
    |  5  | 18  | 31  | 12  | ---- Index 5 ------> | ... |  ...   |  ...  |  ...  |
    +-----+-----+-----+-----+                      |  5  | 0.2902 | 0.063 | 0.063 |
    |  2  | 31  | 31  | 18  |                      | ... |  ...   |  ...  |  ...  |
    +-----+-----+-----+-----+                      | 255 | 1.0000 | 1.000 | 1.000 |
                                                   +-----+--------+-------+-------+
```

1.  **Image Array (`img2`):** An $M \times N$ matrix of integers (`uint8`), where each entry is a pointer/index into the colormap.
2.  **Color Map Matrix (`map`):** A $K \times 3$ lookup table (typically $K = 256$) containing the normalized floating-point RGB components (`double` from $0.0$ to $1.0$) for each index.

#### Memory Comparison Example (from Slide 40):

For an image of size $240 \times 256$:

- **TrueColor RGB (`img1`):**
  $$\text{Size} = 240 \times 256 \times 3 = \mathbf{184,320\text{ bytes}} \ (\approx 180\text{ KB})$$
- **Indexed Representation (`img2` + `map`):**
  - Image Array: $240 \times 256 \times 1\text{ byte} = 61,440\text{ bytes}$
  - Colormap: $256 \times 3 \times 8\text{ bytes (double)} = 6,144\text{ bytes}$
  - Total: $61,440 + 6,144 = \mathbf{67,584\text{ bytes}}$
- **Storage Savings:** Reduces required memory to **$36.7\%$** of the original uncompressed RGB image.
